# NASA POWER: de onde vieram os números

- API mensal regional, https://power.larc.nasa.gov/api/temporal/monthly/regional, comunidade AG, 1981–2025; acesso em 26/11/2026; versões da API: ver execuções anteriores.
- Média regional ponderada pelo número de pixels entregues do SAB em cada célula (pesos_celulas.csv).
- Mês com menos de 90% do peso com dado fica de fora.
